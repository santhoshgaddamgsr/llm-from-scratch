# llm-from-scratch

Learning LLM internals by building them: micrograd, PyTorch basics,
a GPT trained on tiny Shakespeare, a BPE tokenizer, and a small-scale GPT-2 reproduction.

This is Phase 1 of my text-to-SQL LLM project.
